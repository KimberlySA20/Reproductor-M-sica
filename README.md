# Reproductor de Música

Un reproductor de música web moderno con autenticación de usuarios.

## Características Principales

- 🎵 Reproducción de música en streaming
- 🔐 Autenticación segura de usuarios
- 📱 Interfaz responsive
- 🎧 Control de reproducción completo

## Iniciar Sesión

Para acceder al reproductor, sigue estos pasos:

1. Navega a la página de inicio de sesión
2. Ingresa tus credenciales:
   - Correo electrónico
   - Contraseña
3. Haz clic en "Iniciar Sesión"

### ¿No tienes una cuenta?

1. Haz clic en "Registrarse" en la página de inicio de sesión
2. Completa el formulario con tus datos
3. Confirma tu correo electrónico
4. ¡Listo! Ya puedes iniciar sesión

## Requisitos del Sistema

- Navegador web actualizado (Chrome, Firefox, Safari, Edge)
- Conexión a Internet estable
- Altavoces o auriculares

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/reproductor-musica.git
   cd reproductor-musica
   ```

2. Instala las dependencias:
   ```bash
   npm install
   ```

3. Inicia el servidor de desarrollo:
   ```bash
   npm start
   ```
